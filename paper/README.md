# Accompanying manuscript

This directory contains the final minor-revision manuscript used to define the repository's
mathematical contracts.

- `manuscript.pdf`: rendered 41-page paper.
- `manuscript.tex`: standalone LaTeX source.
- `references.bib`: bibliography.
- `figures/`: generated figure assets.
- `make_figures.py`: figure-generation script.
- `MINOR_REVISION_NOTES.md`: changes made in response to the second referee report.

The Python package does not infer that a run satisfies every theorem hypothesis automatically.
`docs/paper-mapping.md` states which formulas and schedules are implemented and where conservative
geometric upper bounds are used.
