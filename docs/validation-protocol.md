# Numerical validation protocol

The repository follows the paper's preregistered principles:

- record launch radius, death radius, target radius, target diameter, `rho`, and `varrho`;
- replicate the complete correlated operator construction, not only individual walkers;
- use common, predeclared fitting windows;
- fit the predicted two-term asymptotic model before a pure power law;
- propagate uncertainty in the estimated center;
- use ensembles of independent aggregates at multiple sizes;
- include continuum-sensitive discrepancies in addition to angular-bin TV;
- benchmark against exact Poisson return at matched measured or certified accuracy.
